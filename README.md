# DnD Atlas

Статический прототип сайта для виртуального стола в стиле owlbear.rodeo.

## Как запустить

1. Откройте `index.html` в браузере.
2. Или запустите любой локальный сервер (например, `python -m http.server`).

## Состав

- `index.html` — структура страниц и секций.
- `styles.css` — визуальный стиль, сетка, компоненты.
- `script.js` — небольшой интерактив (бросок d20).
