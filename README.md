# DnD Atlas

Статический прототип сайта для виртуального стола в стиле owlbear.rodeo.

## Как запустить

1. Откройте `index.html` в браузере.
2. Для списка комнат откройте `rooms.html`.
3. Для кабинета мастера откройте `master.html`.
4. Или запустите любой локальный сервер (например, `python -m http.server`).

## Состав

- `index.html` — главная страница с разделами и макетами интерфейса.
- `rooms.html` — страница комнат и кампаний.
- `master.html` — личный кабинет мастера.
- `styles.css` — визуальный стиль, сетка, компоненты.
- `script.js` — небольшой интерактив (бросок d20).
